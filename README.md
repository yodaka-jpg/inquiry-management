# Gate1 提出物

## 1. 起動手順
(環境構築コマンドと起動コマンドを書く)

## 2. 動作確認手順
(どの画面でどう操作すると、何が起きるかを書く)

## 3. 実装できなかった箇所
(できていない項目と、その理由)

## 4. セルフチェック結果
(13 項目に○×を記入。×の理由も書く)

## 5. モック画像一覧
(ファイル名と、それが何の状態かの説明)

## 6. 振り返り
6-1. 実装前に判断に迷った箇所はありましたか。
あったなら、それは仕様書のどこが不足していたからですか。

6-2. 最初の AI プロンプトを見返して、要件定義書のどの部分を伝え忘れましたか。

6-3. もしこの要件定義書が無く、「問い合わせのステータスを変えられるようにして」
とだけ言われていたら、何を確認しに行きましたか。
思いつく限り箇条書きにしてください(10 個以上を目標に)。
